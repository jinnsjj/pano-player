功能与使用说明

PanoPlayer 是一个在浏览器中运行的本地全景视频与空间音频播放器，可查看画面、监听 FOA，并实时分析声音方向与响度。

开始播放

  1. 点击 Open，或将一个本地文件拖入网页。支持选择 MP4、WebM、MOV、MKV、WAV 和 FLAC。
  2. 点击播放按钮。进度条可跳转时间，右侧可调整音量或静音；有多个音轨时，在 Audio → Track 中切换。
  3. 再次打开文件会替换当前媒体；右上角关闭按钮释放当前文件，全屏按钮扩大工作区。

全景与视角

Panorama / Perspective
播放条上的两个视图按钮分别显示展开全景和透视视角。透视模式可拖拽转向、滚轮缩放，使用重置按钮回到正前方。
Projection / Layout / Rotation
按素材选择 360° ERP、180° ERP 或 EAC。Auto 仅按画面比例推测；SBS 取左眼，TB 取上眼，不是 VR 双眼输出。Rotation 用于修正画面旋转。
Grid / PanoView
Grid 显示方向网格；PanoView 在透视模式中显示全景缩略图与当前视野范围。Aspect 可切换透视画面的 4:3 / 16:9 比例。

空间音频与分析

FOA 监听
根据素材设置 Channel（WYZX / WXYZ）和 Norm（SN3D / N3D）。Binaural 适合耳机，听音方向随透视视角变化；Stereo 保持录音坐标方向。
PowerMap
勾选后显示 FOA 声能方向热图。旁边菜单可选择 MUSIC / PWD、MUSIC 的假设声源数及透明度。它用于定性观察，不是声源分离或校准定位结果。
Meters
显示监听输出的 Peak、True Peak、RMS、LUFS 和 LRA。短片段或刚开始播放时，部分统计需要积累数据；表头问号提供各指标说明。

四声道不一定是 FOA。六声道按“4 路 FOA + 2 路头锁定立体声”解释，不适用于普通 5.1。普通单声道、立体声使用 Bypass，空间音频控件会禁用。请按素材真实声道语义设置。

本地处理与隐私

  • 文件直接在本机浏览器中读取、解码和分析，不上传媒体。网站只提供网页程序资源，不使用云端转码。
  • 仅在本机保存设置，不保存文件内容、路径或访问权限。刷新整个网页后需要重新选择文件。
